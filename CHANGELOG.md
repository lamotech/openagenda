# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-11-23

### Added

- OpenAgenda v0.1 end-to-end demo: committees, meetings, agenda items with OpenCase references,
  approval and immutable agenda snapshots, political treatment and decisions, forwarding between
  committees, decision protocol (HTML), idempotent journalization via a mock OpenCase adapter,
  public portal and API, audit log, role-based access control, demo seeder and tests.
